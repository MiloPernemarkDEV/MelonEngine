# Melon Engine

Melon Engine is a custom game engine built from scratch in C++.

> **🚧 Work in Progress**
>
> Melon Engine is currently under active development. The architecture and systems are still evolving, and many features are incomplete or experimental.

## Current Focus

- Rendering
- Low-level engine systems

The project is primarily a learning and experimentation project focused on exploring game engine architecture and low-level systems.
